# Onboard

Your job is finished when the account is **created** and the badge is **issued**.

## Tools

Tools: create_account, issue_badge.

Each tool is a script: `python tools/<tool>.py <employee>`.

## Workflow

1. Create the employee's account with `create_account`.
2. Issue the badge with `issue_badge`.
