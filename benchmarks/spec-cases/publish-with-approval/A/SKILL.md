# Publish

Your job is finished when the report is **published**.

## Tools

Tools: draft, approve, publish.

`publish` requires the report to be **approved** before it will run. Each tool is a script:
`python tools/<tool>.py`.

## Workflow

1. Draft the report with `draft`.
2. Approve it with `approve`.
3. Publish it with `publish`.
