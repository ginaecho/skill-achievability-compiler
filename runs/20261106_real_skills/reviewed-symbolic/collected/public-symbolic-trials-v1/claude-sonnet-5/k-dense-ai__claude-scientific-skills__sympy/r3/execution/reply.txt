I created `/work/roots.py`, a standard-library + SymPy CLI that:

3. **Parses the expression safely** via Python's `ast` module with an explicit allow-list (`BinOp` for `+ - * / **`, `UnaryOp` for unary `+/-`, integer `Constant`, and `Name` for `x` only) — rejecting function calls, attributes, floats, or any other construct. 6. Formats every rational value via `str()` (SymPy's canonical reduced rational string with positive denominator, integers without `/1`).
7. Prints a single JSON object `{"cases": [...]}` to stdout and exits 0; non-conforming/invalid "roots(" lines are silently skipped rather than causing a crash.
