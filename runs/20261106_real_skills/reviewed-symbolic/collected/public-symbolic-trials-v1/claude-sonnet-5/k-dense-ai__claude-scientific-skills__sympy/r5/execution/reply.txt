I built and verified `/work/roots.py`, a standard-library + SymPy CLI that:

1. **Reads** the given Markdown path as inert text (no execution of fenced code, imports, or document instructions).
2. **Scans** each physical line; only lines whose *stripped* text begins with `roots(` are processed (indentation before `roots(` is allowed; everything else, including stray mentions of the word, is ignored).
3. **Extracts** the argument list by depth-tracking the parentheses (not naive regex), splits on the top-level comma, requires the second argument to be exactly `x`, and validates the first argument only contains digits, `x`, whitespace, `+ - * / ( )` (rejecting anything else, e.g. no negative exponents) before parsing it with SymPy's `parse_expr` — so only a bounded arithmetic mini-language is ever evaluated, never arbitrary document code.
4. **Computes** the polynomial over the exact rational field (`Poly(..., domain='QQ')`), finds all linear factors via `factor_list()` to obtain every rational root and its multiplicity, then derives `residual_coefficients` by performing exact polynomial division of the **original** polynomial by each monic `(x - root)**multiplicity` factor in turn (not by normalizing scalars from `factor_list`), preserving the original leading scalar as required.
5. **Formats** every coefficient and root as canonical reduced rational strings (bare integers when the denominator is 1, `p/q` with positive `q` otherwise), sorts `rational_roots` ascending, and emits a single JSON object `{"cases": [...]}` to stdout with nothing on stderr, exiting 0.
