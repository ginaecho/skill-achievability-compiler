**How it works:**
- **Reading the document:** it only treats the file as text. Nothing in it is run, imported or passed to `eval`/`sympify`. It picks out lines whose stripped text starts with `roots(` and checks that each ends in `, x)` with an optional `#` comment.
- **Parsing:** a small parser handles only the allowed syntax: integers, `x`, parentheses, `+`, `-`, `*`, division by a nonzero constant, and `**` with a literal power from 0 to 8. All arithmetic uses exact fractions.
- **Finding roots:** SymPy factors each polynomial over the rationals, and every linear factor gives a rational root and its multiplicity. The residual comes from dividing the original polynomial by each `(x - root)` factor. That division must come out exact, and the original leading coefficient is kept.
- **Output:** numbers are reduced fraction strings with a positive denominator and no `/1`. Roots are sorted ascending and multiplicities are JSON integers. Constant polynomials are left unchanged with no roots, and a document with no matches gives `{"cases": []}`.

- **No matches:** a document with no `roots(` lines gave `{"cases": []}`.
- **Size limit:** 32 random polynomials of degree up to 8 all matched the independent calculation.

Input that breaks the stated rules (for example, a variable other than `x` or a power above 8) stops the program with an error. The task only requires correct behaviour for valid input.
