I wrote `/work/roots.py` and ran it in the sandbox. It works on the supplied document, on a changed document with several examples, on a document with no examples, and on a worst-case-size input.

**Result on `/inputs/core-capabilities.md`:** the file has one line that starts with `roots(`: `roots(x**3 - 6*x**2 + 9*x, x)  # {0: 1, 3: 2}`. The program printed:
```json
{"cases": [{"coefficients": ["1", "-6", "9", "0"], "rational_roots": [{"root": "0", "multiplicity": 1}, {"root": "3", "multiplicity": 2}], "residual_coefficients": ["1"]}]}
```
It exited with 0, wrote nothing to stderr and took about 3.5 s.

**How it works:**
- **Safe parsing:** it reads the file as plain UTF-8 text and never runs any of the document's code. On each matching line it drops the `# comment` and checks that the line is exactly `roots(EXPR, x)`. A small parser then reads the expression and accepts only integer numbers, `x`, `+ - *`, division by a nonzero constant and powers 0 to 8. Anything else is rejected.
- **Exact arithmetic:** all coefficients are exact fractions, with no floating point.
- **Roots:** SymPy factors the polynomial over the rationals, and every linear factor gives a rational root and its multiplicity. Factors that don't split, like `x**2+1`, stay in the residual.
- **Residual:** it divides the original polynomial (keeping its leading coefficient) by each `(x-root)` the right number of times. It raises an internal error if any division leaves a remainder, so a wrong root can't slip through.
- **Output format:** coefficients are listed highest degree first, with zeros in the middle kept. Numbers are reduced fraction strings like `"-4/3"`, with integers shown without `/1`. Roots are sorted ascending, and each multiplicity is a JSON integer.

**Checks I ran (separate processes, using test files I deleted afterwards):**
- **Several examples:** I tested a fraction root of multiplicity 3 next to `x**2+1`, a constant `7`, a negative leading coefficient with a zero root, `x**8-1`, division by a constant, a repeated example kept in order, and a non-matching `x = roots(x, x)` line, which was correctly ignored. All results were right and complete.
- **No examples:** printed `{"cases": []}` and exited with 0.
- **Worst-case size:** 32 lines of degree-8 polynomials with fraction coefficients ran in about 3.4 s, well inside the 15-second limit.

If an input is invalid, the program prints an error to stderr and exits with a nonzero code. I didn't install anything or change `/inputs`, and `/work` now holds only `roots.py`.
