Created the CLI at:

`/work/roots.py`

It reads one Markdown path, processes only stripped lines starting with `roots(` in the required `roots(EXPR, x)` form (with optional trailing `#` comment), computes exact rational roots with multiplicities using SymPy over `QQ`, computes residual coefficients by dividing out corresponding monic linear factors, and prints exactly one JSON object with key `cases` to stdout (newline-terminated), with no stderr output during valid runs.
