Implemented.

Created the CLI at:

`/work/roots.py`

It reads one Markdown path argument, parses only lines whose stripped text starts with `roots(` in the required `roots(EXPR, x)` form, computes exact rational roots with multiplicities, computes residual coefficients after dividing by monic `(x-root)^m` factors, and prints exactly one JSON object (`{"cases": [...]}`) plus newline to stdout.
