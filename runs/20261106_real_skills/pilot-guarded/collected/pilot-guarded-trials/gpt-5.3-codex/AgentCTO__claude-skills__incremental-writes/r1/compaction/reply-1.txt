Skill `incremental-write-targeted-replace`.
Roles: `agent`.
Tool `read_target_file` (owner `agent`): via `execute_python`; adds `file_read_before_edit`, `target_text_found`.
Tool `attempt_targeted_replace` (owner `agent`): via `execute_python`; requires `file_read_before_edit` and `target_text_found`; adds `write_attempted`; picks `write_status` with `write_status` == 1 or `write_status` == -1.
Tool `verify_exact_edit` (owner `agent`): via `execute_python`; requires `write_attempted` and `write_status` == 1; adds `exact_replacement_applied`, `nothing_else_changed`.
Tool `report_runtime_refusal` (owner `agent`): via `reply`; requires `write_attempted` and `write_status` == -1; adds `refusal_reported`.
Initially true: none.
Initially: `write_status` == 0.
Goal: any of (all of (`exact_replacement_applied`, `nothing_else_changed`), `refusal_reported`).
Protocol:
  - `agent` uses `read_target_file`.
  - `agent` uses `attempt_targeted_replace`.
  - `agent` chooses one of (external):
    - branch `write_succeeded` (assuming `write_status` == 1):
      - `agent` uses `verify_exact_edit`.
    - branch `write_refused` (assuming `write_status` == -1):
      - `agent` uses `report_runtime_refusal`.
