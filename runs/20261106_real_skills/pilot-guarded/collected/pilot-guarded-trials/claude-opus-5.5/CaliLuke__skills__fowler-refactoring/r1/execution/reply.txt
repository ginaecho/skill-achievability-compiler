I edited `/work/textmask.py` so the sorting now lives in a new function, `name_tokens(name)`, and `masked` calls it. When I ran the old and new versions side by side on 11 test inputs, every output matched.

**The file now:**
```python
import re


def name_tokens(name: str) -> list[str]:
    """The unique name and its hyphen-separated parts, longest first."""
    return sorted({name} | set(name.split("-")), key=len, reverse=True)


def masked(text: str, name: str) -> str:
    """The text with the skill's own name and its parts replaced, lower-cased."""
    t = text.lower()
    for tok in name_tokens(name):
        if len(tok) >= 3:
            t = re.sub(r"\b" + re.escape(tok) + r"\b", "x", t)
    return t
```

- **Same behaviour:** The tokens are built and sorted exactly as before. The 3-character minimum stays in `masked`. Matching is still case-sensitive: the text is lower-cased but the name isn't, so a capitalised name like `Fowler` doesn't match anything.
- **Structure:** The file has only the `re` import and these two pure functions.
