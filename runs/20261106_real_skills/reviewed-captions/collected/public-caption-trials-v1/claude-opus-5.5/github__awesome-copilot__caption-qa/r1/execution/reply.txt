That exit code 1 is the checker reporting a real problem in the captions, not a fault in the script.

**How it checks:** every limit is compared in whole milliseconds, with no rounding or tolerance:
- **Duration** fails if `dur*6 < 5000` (under 5/6 second) or `dur > 7000`.
- **Reading speed** fails if `chars*1000 > 20*dur`, and is only checked when the duration is above zero.
- **Gap** fails if `0 ≤ gap` and `gap*24 < 2000`. A negative gap is reported as `overlap` instead.
