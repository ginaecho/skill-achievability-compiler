**Finding:** `canonicalize_url` uses `urllib.parse.quote(..., safe="/:?#[]@!$&'()*+,;=")`, which does not include `%` in its safe set, so any literal `%` in the input gets re-encoded on each pass.

- input: `"%"`
- once = `canonicalize_url("%")` = `"%25"`
- twice = `canonicalize_url("%25")` = `"%2525"`

Since `once != twice`, idempotence fails: `f(f(x)) != f(x)`.

Written verbatim to `/work/counterexample.json`:
```json
{"input": "%", "once": "%25", "twice": "%2525"}
```
