**What the module does**
- The top level contains only `import base64`, `import hashlib`, `import hmac` and one function definition.
- `verify_webhook(raw_body, hmac_header, secret)`:
  - Returns `False` if the header is `None` or empty.
  - Returns `False` if the header contains non-ASCII characters, instead of letting `compare_digest` raise an error.
  - Otherwise, it computes HMAC-SHA256 over the exact `raw_body` bytes, keyed with `secret.encode("utf-8")`, and Base64-encodes the result. It then compares that with the header using `hmac.compare_digest`.
  - The body is never parsed, decoded or re-serialized.
