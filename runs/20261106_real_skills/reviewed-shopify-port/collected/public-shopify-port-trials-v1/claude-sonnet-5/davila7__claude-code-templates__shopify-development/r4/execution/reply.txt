```python
import base64
import hashlib
import hmac


def verify_webhook(raw_body: bytes, hmac_header: str | None, secret: str) -> bool:
    if not hmac_header:
        return False
    try:
        hmac_header.encode("ascii")
    except UnicodeEncodeError:
        return False

    digest = hmac.new(secret.encode("utf-8"), raw_body, hashlib.sha256).digest()
    expected = base64.b64encode(digest).decode("ascii")

    return hmac.compare_digest(hmac_header, expected)
```

**Design choices matching the spec:**
- Operates on raw `bytes` directly — no parsing/decoding/re-serialization of the body.
- `secret` encoded as UTF-8 for the HMAC key (matches Node's default string encoding).
- Non-ASCII header values raise `UnicodeEncodeError` internally, which is caught and turned into `False` (no exception propagates).
- `None`/empty header short-circuits to `False` via `if not hmac_header`.
- Uses `hmac.compare_digest` for the final comparison, as required.
- Module body contains only the three stdlib imports and the function definition — verified via `ast` parsing that no other top-level statements exist.
