I edited `/work/batch.py` so every JSON record it writes to stderr now has an integer `sequence` field. It starts at 0 on each run and goes up by one per record, across start, progress, item-failed and summary events. I ran all eight scenarios plus a no-argument run, and stdout and exit codes match the original exactly.

**The change:** All stderr output goes through one function, `emit`, so the edit is only there. It now keeps a counter, adds it as the last field of each record, then increments it. I didn't change processing, scenario names, defaults or exit codes. All existing fields stay in their original order, and `sequence` is added at the end.

**Test results:** I saved a copy of the original file, ran the original and the edited version on the same inputs, then deleted the copy. `/work/batch.py` is the only file left in `/work`. For each run I captured stdout, stderr and the exit code separately. The live scenario was given a newline on stdin to release its test pause.

For every run, these all matched the original:
