I edited `/work/batch.py` so every JSON record it writes to stderr now has an integer `sequence` field. I ran all eight scenarios against both the original and the edited file, and all checks passed.

**The change:** the counter starts at 0 on each run and goes up by 1 after each record is written, so it is shared across start, progress, item-failed and summary events. `sequence` is added as the last key; all other fields keep their order and values. Nothing else in the file changed: processing, counters, status, exit-code logic, stdout and scenario handling are as before. Only the standard library is used.

```python
    sequence = 0

    def emit(event, **fields):
        nonlocal sequence
        record = {..., **fields, "sequence": sequence}
        sequence += 1
        print(json.dumps(record), file=sys.stderr, flush=True)
```

**Checks I ran:** I saved the original as `/tmp/batch_orig.py`, captured its output as a baseline, then ran the edited script twice per scenario. A newline was sent on stdin each time to release the live scenario's fixture gate.
