Tool `inspect_pages` (owner `agent`): requires `pages_rendered`; adds `pages_inspected`.
Tool `fix_issues` (owner `agent`): requires `pages_inspected`; removes `pages_inspected`, `pages_rendered`.
Tool `deliver_pdf` (owner `agent`): requires `pages_inspected`; adds `pdf_delivered`.
Goal: `pdf_delivered`.
Protocol:
  - `agent` uses `generate_pdf`.
  - loop `refine`:
    - `agent` uses `render_pages`.
    - `agent` uses `inspect_pages`.
    - `agent` chooses one of (observed):
      - branch `defects_found`:
        - `agent` uses `fix_issues`.
        - repeat `refine`.
      - branch `no_defects`:
        - `agent` uses `deliver_pdf`.
