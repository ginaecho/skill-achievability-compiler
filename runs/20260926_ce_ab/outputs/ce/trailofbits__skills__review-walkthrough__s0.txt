```ce
Skill `review-walkthrough`.
Roles: `agent`, `user`.
Tool `resolve_base` (owner `agent`): adds `base_resolved`.
Tool `capture_diff` (owner `agent`): requires `base_resolved`; adds `diff_captured`.
Tool `read_source_context` (owner `agent`): requires `diff_captured`; adds `context_read`.
Tool `write_review_data` (owner `agent`): requires `diff_captured` and `context_read`; adds `data_written`.
Tool `render_walkthrough` (owner `agent`): requires `data_written`; adds `walkthrough_rendered`.
Tool `open_walkthrough` (owner `agent`): requires `walkthrough_rendered`; adds `walkthrough_opened`.
Tool `report_path` (owner `agent`): requires `walkthrough_rendered`; adds `path_reported`.
Goal: `walkthrough_rendered` and (`walkthrough_opened` or `path_reported`).
Protocol:
  - `agent` uses `resolve_base`.
  - `agent` uses `capture_diff`.
  - `agent` uses `read_source_context`.
  - `agent` uses `write_review_data`.
  - `agent` uses `render_walkthrough`.
  - `agent` chooses one of (external):
    - branch `headless`:
      - `agent` uses `report_path`.
    - branch `browser_available`:
      - `agent` uses `open_walkthrough`.
```
