```ce
Skill `finishing-a-development-branch`.
Roles: `agent`, `user`.
Tool `run_tests` (owner `agent`): adds `tests_verified`.
Tool `detect_environment` (owner `agent`): adds `environment_detected`.
Tool `determine_base_branch` (owner `agent`): requires `environment_detected`; adds `base_branch_confirmed`.
Tool `present_options` (owner `agent`): requires `tests_verified` and `base_branch_confirmed`; adds `options_presented`.
Tool `merge_locally` (owner `agent`): requires `options_presented`; adds `merged`.
Tool `push_and_create_pr` (owner `agent`): requires `options_presented`; adds `pr_created`.
Tool `keep_as_is` (owner `agent`): requires `options_presented`; adds `kept_as_is`.
Tool `cleanup_workspace` (owner `agent`): requires `merged`; adds `cleaned_up`.
Goal: `tests_verified` and `options_presented` and ((`merged` and `cleaned_up`) or `pr_created` or `kept_as_is`).
Protocol:
  - `agent` uses `run_tests`.
  - `agent` uses `detect_environment`.
  - `agent` uses `determine_base_branch`.
  - `agent` uses `present_options`.
  - `user` chooses one of (observed):
    - branch `merge`:
      - `agent` uses `merge_locally`.
      - `agent` uses `cleanup_workspace`.
    - branch `push_pr`:
      - `agent` uses `push_and_create_pr`.
    - branch `keep`:
      - `agent` uses `keep_as_is`.
```
