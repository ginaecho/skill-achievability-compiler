```ce
Skill `preset`.
Roles: `agent`, `user`.
Tool `verify_auth` (owner `agent`): adds `auth_verified`.
Tool `get_project` (owner `agent`): requires `auth_verified`; adds `project_found`.
Tool `select_model` (owner `agent`): requires `project_found`; adds `model_selected`.
Tool `check_region_capacity` (owner `agent`): requires `model_selected`; adds `capacity_checked`.
Tool `query_all_regions` (owner `agent`): requires `capacity_checked`; adds `regions_queried`.
Tool `select_region_project` (owner `agent`): requires `regions_queried`; adds `region_project_selected`.
Tool `deploy_model` (owner `agent`): requires `capacity_checked`; adds `deployed`.
Tool `monitor_deployment` (owner `agent`): requires `deployed`; adds `deployment_monitored`.
Goal: `deployed` and `deployment_monitored`.
Protocol:
  - `agent` uses `verify_auth`.
  - `agent` uses `get_project`.
  - `agent` uses `select_model`.
  - `agent` uses `check_region_capacity`.
  - `agent` chooses one of (external):
    - branch `has_capacity`:
      - `agent` uses `deploy_model`.
      - `agent` uses `monitor_deployment`.
    - branch `no_capacity`:
      - `agent` uses `query_all_regions`.
      - `user` chooses one of (observed):
        - branch `region_selected`:
          - `agent` uses `select_region_project`.
          - `agent` uses `deploy_model`.
          - `agent` uses `monitor_deployment`.
        - branch `abort`: none.
```
