```ce
Skill `receiving-code-review`.
Roles: `agent`, `reviewer`.
Tool `read_feedback` (owner `agent`): adds `feedback_read`.
Tool `ask_clarification` (owner `agent`): requires `feedback_read`; adds `clarification_asked`.
Tool `verify_against_codebase` (owner `agent`): requires `feedback_read`; adds `feedback_verified`.
Tool `implement_fix` (owner `agent`): requires `feedback_verified`; adds `fix_implemented`.
Tool `run_tests` (owner `agent`): requires `fix_implemented`; adds `fix_tested`.
Tool `push_back` (owner `agent`): requires `feedback_verified`; adds `pushback_given`.
Goal: `feedback_read` and (`clarification_asked` or (`feedback_verified` and (`fix_tested` or `pushback_given`))).
Protocol:
  - `agent` uses `read_feedback`.
  - `reviewer` chooses one of (observed):
    - branch `clear`:
      - `agent` uses `verify_against_codebase`.
      - `agent` chooses one of (observed):
        - branch `sound`:
          - `agent` uses `implement_fix`.
          - `agent` uses `run_tests`.
        - branch `unsound`:
          - `agent` uses `push_back`.
    - branch `unclear`:
      - `agent` uses `ask_clarification`.
```
