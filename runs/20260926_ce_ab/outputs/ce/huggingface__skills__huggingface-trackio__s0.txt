```ce
Skill `huggingface-trackio`.
Roles: `agent`.
Tool `trackio_init` (owner `agent`): adds `tracking_initialized`.
Tool `trackio_log` (owner `agent`): requires `tracking_initialized`; adds `metrics_logged`.
Tool `trackio_alert` (owner `agent`): requires `tracking_initialized`; adds `alert_fired`.
Tool `trackio_finish` (owner `agent`): requires `tracking_initialized`; adds `tracking_finished`.
Tool `trackio_list_alerts` (owner `agent`): requires `tracking_initialized`; adds `alerts_retrieved`.
Tool `trackio_get_metric` (owner `agent`): requires `metrics_logged`; adds `metrics_retrieved`.
Goal: `tracking_initialized` and `metrics_logged` and `tracking_finished` and `metrics_retrieved`.
Protocol:
  - `agent` uses `trackio_init`.
  - loop `training_loop`:
    - `agent` uses `trackio_log`.
    - `agent` chooses one of (observed):
      - branch `alert_condition`:
        - `agent` uses `trackio_alert`.
      - branch `no_alert`: none.
    - `agent` chooses one of (observed):
      - branch `continue_training`:
        - repeat `training_loop`.
      - branch `done`: none.
  - `agent` uses `trackio_finish`.
  - `agent` uses `trackio_list_alerts`.
  - `agent` uses `trackio_get_metric`.
```
