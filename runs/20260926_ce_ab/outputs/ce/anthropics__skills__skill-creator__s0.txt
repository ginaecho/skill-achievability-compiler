```ce
Skill `skill-creator`.
Roles: `agent`, `user`, `subagent`.
Tool `write_skill` (owner `agent`): adds `skill_drafted`.
Tool `write_evals` (owner `agent`): requires `skill_drafted`; adds `evals_written`.
Tool `run_eval` (owner `agent`): requires `evals_written`; adds `runs_completed`.
Tool `grade_runs` (owner `agent`): requires `runs_completed`; adds `graded`.
Tool `aggregate_benchmark` (owner `agent`): requires `graded`; adds `benchmark_ready`.
Tool `launch_viewer` (owner `agent`): requires `benchmark_ready`; adds `viewer_launched`.
Tool `read_feedback` (owner `agent`): requires `viewer_launched`; adds `feedback_received`.
Tool `improve_skill` (owner `agent`): requires `feedback_received`; adds `skill_improved`.
Tool `package_skill` (owner `agent`): requires `skill_improved`; adds `skill_packaged`.
Goal: `skill_packaged`.
Protocol:
  - `agent` uses `write_skill`.
  - `agent` uses `write_evals`.
  - spawn `subagent`.
  - `agent` uses `run_eval`.
  - `agent` uses `grade_runs`.
  - `agent` uses `aggregate_benchmark`.
  - `agent` uses `launch_viewer`.
  - `agent` uses `read_feedback`.
  - `user` chooses one of (observed):
    - branch `satisfied`:
      - `agent` uses `improve_skill`.
      - `agent` uses `package_skill`.
    - branch `wants_more_iteration`:
      - `agent` uses `improve_skill`.
      - loop `iterate`:
        - `agent` uses `run_eval`.
        - `agent` uses `grade_runs`.
        - `agent` uses `aggregate_benchmark`.
        - `agent` uses `launch_viewer`.
        - `agent` uses `read_feedback`.
        - `agent` uses `improve_skill`.
        - repeat `iterate`.
```
