```ce
Skill `systematic-debugging`.
Roles: `agent`.
Tool `investigate_root_cause` (owner `agent`): adds `root_cause_found`.
Tool `write_failing_test` (owner `agent`): requires `root_cause_found`; adds `test_written`.
Tool `implement_fix` (owner `agent`): requires `test_written`; adds `fix_implemented`.
Tool `verify_fix` (owner `agent`): requires `fix_implemented`; adds `fix_verified`.
Goal: `fix_verified`.
Protocol:
  - loop `debug_loop`:
    - `agent` uses `investigate_root_cause`.
    - `agent` uses `write_failing_test`.
    - `agent` uses `implement_fix`.
    - `agent` uses `verify_fix`.
    - `agent` chooses one of (observed):
      - branch `resolved`: none.
      - branch `retry`:
        - repeat `debug_loop`.
```
