Skill `pr-review`.
Roles: `agent`, `user`.
Tool `identify_pr` (owner `agent`): adds `pr_identified`.
Tool `ensure_branch_available` (owner `agent`): requires `pr_identified`; adds `branch_available`.
Tool `gather_context` (owner `agent`): requires `branch_available`; adds `context_gathered`.
Tool `categorize_changes` (owner `agent`): requires `context_gathered`; adds `changes_categorized`.
Tool `review_code` (owner `agent`): requires `changes_categorized`; adds `findings_ready`.
Tool `present_findings` (owner `agent`): requires `findings_ready`; adds `findings_presented`.
Tool `post_review` (owner `agent`): requires `findings_presented`; adds `review_posted`.
Tool `confirm_none_posted` (owner `agent`): requires `findings_presented`; adds `none_selected`.
Goal: `findings_presented` and (`review_posted` or `none_selected`).
Protocol:
  - `agent` uses `identify_pr`.
  - `agent` uses `ensure_branch_available`.
  - `agent` uses `gather_context`.
  - `agent` uses `categorize_changes`.
  - `agent` uses `review_code`.
  - `agent` uses `present_findings`.
  - `user` chooses one of (observed):
    - branch `post_selected`:
      - `agent` uses `post_review`.
    - branch `post_none`:
      - `agent` uses `confirm_none_posted`.
