Skill `doc-coauthoring`.

Tool `create_scaffold` (owner `agent`): requires `context_gathered`; adds `scaffold_created`.
Tool `draft_section` (owner `agent`): requires `scaffold_created`; adds `sections_drafted`.
Tool `refine_section` (owner `agent`): requires `sections_drafted`; adds `sections_refined`.
Tool `test_with_subagent` (owner `agent`): requires `sections_refined`; adds `reader_tested`.
Tool `instruct_manual_test` (owner `agent`): requires `sections_refined`; adds `reader_tested`.
Tool `final_review` (owner `agent`): requires `reader_tested`; adds `doc_complete`.
Goal: `doc_complete`.
Protocol:
  - `agent` uses `offer_workflow`.
  - `user` chooses one of (observed):
    - branch `accept`:
      - `agent` uses `gather_context`.
      - `agent` uses `create_scaffold`.
      - loop `sections`:
        - `agent` uses `draft_section`.
        - `agent` uses `refine_section`.
        - repeat `sections`.
      - `user` chooses one of (observed):
        - branch `subagent_available`:
          - spawn `reader`.
          - `agent` uses `test_with_subagent`.
        - branch `manual_test`:
          - `agent` uses `instruct_manual_test`.
      - `agent` uses `final_review`.
    - branch `decline`: none.
