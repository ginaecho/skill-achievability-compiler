```ce
Skill `executing-plans`.
Roles: `implementer`, `reviewer`.
Tool `setup_workspace` (owner `implementer`): adds `workspace_ready`.
Tool `read_plan_spec` (owner `implementer`): requires `workspace_ready`; adds `plan_read`.
Tool `preflight_scan` (owner `implementer`): requires `plan_read`; adds `preflight_done`.
Tool `task_start` (owner `implementer`): requires `preflight_done`; adds `task_briefed`.
Tool `work_steps` (owner `implementer`): requires `task_briefed`; adds `steps_done`.
Tool `commit_task` (owner `implementer`): requires `steps_done`; adds `task_committed`.
Tool `task_done` (owner `implementer`): requires `task_committed`; adds `task_complete`.
Tool `final_review` (owner `reviewer`): requires `task_complete`; adds `review_done`.
Tool `self_review` (owner `implementer`): requires `task_complete`; adds `review_done`.
Tool `fix_pass` (owner `implementer`): requires `review_done`; adds `fixes_applied`.
Tool `delete_workspace` (owner `implementer`): requires `fixes_applied`; adds `workspace_deleted`.
Tool `finish_branch` (owner `implementer`): requires `workspace_deleted`; adds `branch_finished`.
Goal: `branch_finished` and `review_done` and `fixes_applied`.
Protocol:
  - `implementer` uses `setup_workspace`.
  - `implementer` uses `read_plan_spec`.
  - `implementer` uses `preflight_scan`.
  - loop `task_loop`:
    - `implementer` uses `task_start`.
    - `implementer` uses `work_steps`.
    - `implementer` uses `commit_task`.
    - `implementer` uses `task_done`.
    - `implementer` chooses one of (observed):
      - branch `more_tasks`:
        - repeat `task_loop`.
      - branch `no_more_tasks`: none.
  - `implementer` chooses one of (external):
    - branch `has_subagent`:
      - spawn `reviewer`.
      - `reviewer` uses `final_review`.
    - branch `no_subagent`:
      - `implementer` uses `self_review`.
  - `implementer` uses `fix_pass`.
  - `implementer` uses `delete_workspace`.
  - `implementer` uses `finish_branch`.
```
