  - `agent` uses `check_branch`.
  - `agent` chooses one of (external):
    - branch `not_main`:
      - `agent` uses `commit_changes`.
    - branch `on_main`:

        - branch `direct_requested`:
          - `agent` uses `commit_changes`.
        - branch `make_feature_branch`:
          - `agent` uses `create_feature_branch`.
          - `agent` uses `commit_changes`.
