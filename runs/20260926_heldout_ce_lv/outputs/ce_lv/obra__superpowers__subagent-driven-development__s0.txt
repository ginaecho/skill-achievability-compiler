```ce
Skill `subagent-driven-development`.
Roles: `controller`, `implementer`, `reviewer`.
Tool `setup_worktree` (owner `controller`): via `bash`; adds `worktree_ready`.
Tool `write_brief` (owner `controller`): via `write`; requires `worktree_ready`; adds `brief_written`.
Tool `implement_task` (owner `implementer`): via `bash`; requires `brief_written`; adds `task_implemented`.
Tool `review_task` (owner `reviewer`): via `read`; requires `task_implemented`; adds `task_reviewed`.
Tool `fix_task` (owner `implementer`): via `bash`; requires `task_reviewed`; adds `task_implemented`.
Tool `record_ledger` (owner `controller`): via `write`; requires `task_reviewed`; adds `task_complete`.
Tool `final_review` (owner `reviewer`): via `read`; requires `task_complete`; adds `branch_reviewed`.
Tool `cleanup_workspace` (owner `controller`): via `bash`; requires `branch_reviewed`; adds `workspace_cleaned`.
Initially true: none.
Goal: `task_complete` and `branch_reviewed` and `workspace_cleaned`.
Protocol:
  - `controller` uses `setup_worktree`.
  - `controller` uses `write_brief`.
  - spawn `implementer`.
  - `implementer` uses `implement_task`.
  - spawn `reviewer`.
  - `reviewer` uses `review_task`.
  - loop `fix_loop`:
    - `controller` chooses one of (observed):
      - branch `approved`: none.
      - branch `needs_fix`:
        - `implementer` uses `fix_task`.
        - `reviewer` uses `review_task`.
        - repeat `fix_loop`.
  - `controller` uses `record_ledger`.
  - `reviewer` uses `final_review`.
  - `controller` uses `cleanup_workspace`.
```
