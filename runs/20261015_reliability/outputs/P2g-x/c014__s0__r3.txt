Tool `build_report` (owner `agent`): via `bash`; requires `fix_verified` and `all_issues_resolved`; adds `report_sent`.

Goal: `report_sent`.

  - `agent` uses `detect_project`.
  - `user` chooses one of (observed):

    - branch `url_provided`: none.
  - loop `main_loop`:
    - `agent` uses `webpage_inspect`.
    - `user` chooses one of (observed):
      - branch `issue_selected`:
        - `agent` uses `fix_source`.
        - `agent` uses `verify_fix`.
        - `user` chooses one of (observed):
          - branch `fix_succeeded`: none.
          - branch `fix_failed`:
            - loop `retry_loop`:
              - `agent` uses `fix_source`.
              - `agent` uses `verify_fix`.
              - `user` chooses one of (observed):
                - branch `retry_succeeded`: none.
                - branch `retry_exhausted`: none.
              - repeat `retry_loop`.
        - `user` chooses one of (observed):
          - branch `more_issues_exist`:
            - repeat `main_loop`.
          - branch `no_more_issues`:
            - `agent` uses `build_report`.
