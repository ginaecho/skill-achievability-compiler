```ce
Skill `risk-manager`.
Roles: `agent`, `user`.
Tool `define_risk` (owner `agent`): via `ask_user`; picks `r_value` with `r_value` > 0; adds `risk_per_trade_defined`.
Tool `fetch_portfolio` (owner `agent`): via `bash`; adds `portfolio_data_loaded`.
Tool `calc_expectancy` (owner `agent`): via `bash`; requires `win_rate` is set and `avg_win` is set and `avg_loss` is set; sets `expectancy` to (`win_rate` * `avg_win`) - ((1 - `win_rate`) * `avg_loss`); adds `expectancy_calculated`.
Tool `size_position` (owner `agent`): via `bash`; requires `account_value` > 0 and `risk_pct` > 0 and `r_value` > 0; sets `position_size` to `account_value` * `risk_pct` / `r_value`; adds `position_calculated`.
Tool `correl_matrix` (owner `agent`): via `bash`; requires `portfolio_data_loaded`; sets `corr_threat` to true; adds `correlation_analyzed`.
Tool `monte_carlo` (owner `agent`): via `bash`; requires `portfolio_data_loaded`; adds `stress_tested`; picks `max_drawdown` with true.
Tool `hedge_recommend` (owner `agent`): via `bash`; adds `hedging_plan`.
Tool `set_stops` (owner `agent`): via `bash`; requires `r_value` > 0; sets `stop_loss` to `entry_price` - `r_value`; adds `stops_defined`.
Tool `generate_risk_dashboard` (owner `agent`): via `bash`; requires `subject` is set; adds `dashboard_created`.
Tool `write_report` (owner `agent`): via `bash`; adds `report_delivered`.
Initially true: `account_value` is set, `risk_pct` is set, `entry_price` is set.
Initially: `account_value` > 0, `risk_pct` > 0, `entry_price` > 0, `expectancy` == 0, `position_size` == 0, `stop_loss` == 0.
Goal: `report_delivered`.

Protocol:
  - `user` chooses one of (observed):
    - branch `provide_trade_stats`:
      - `user` tells `agent` `win_rate`.
      - `user` tells `agent` `avg_win`.
      - `user` tells `agent` `avg_loss`.
    - branch `skip_stats`: none.
  - `agent` uses `define_risk`.
  - `agent` uses `fetch_portfolio`.
  - `agent` uses `correl_matrix`.
  - `agent` uses `monte_carlo`.
  - `agent` chooses one of:
    - branch `stats_available`:
      - `agent` uses `calc_expectancy`.
    - branch `stats_missing`: none.
  - `agent` uses `size_position`.
  - `agent` uses `set_stops`.
  - `agent` uses `hedge_recommend`.
  - `agent` uses `generate_risk_dashboard`.
  - `agent` uses `write_report`.
```
