```ce
Skill `book-sft-pipeline`.
Roles: `orchestrator`, `extraction_agent`, `segmentation_agent`, `instruction_agent`, `dataset_builder`, `training_agent`, `validation_agent`, `user`.

Tool `extract_epub_text` (owner `extraction_agent`):
  via `bash`;
  requires `epub_file_provided`;
  adds `raw_text_extracted`, `paragraphs_preserved`.

Tool `remove_front_back_matter` (owner `extraction_agent`):
  via `bash`;
  requires `raw_text_extracted`;
  adds `cleaned_text`.

Tool `segment_text` (owner `segmentation_agent`):
  via `bash`;
  requires `cleaned_text`;
  adds `chunks_segmented`;
  sets `chunk_count` to `chunk_count` + 1 for each chunk.

Tool `generate_synthetic_instruction` (owner `instruction_agent`):
  via `bash`;
  requires `chunks_segmented`;
  picks `instruction` with `instruction` != "";
  adds `instruction_generated`.

Tool `build_dataset` (owner `dataset_builder`):
  via `bash`;
  requires `instruction_generated` and `chunks_segmented`;
  adds `dataset_ready`;
  sets `example_count` to `example_count` + `variants`.

Tool `train_lora` (owner `training_agent`):
  via `bash`;
  needs `tinker_platform`;
  requires `dataset_ready`;
  adds `lora_adapter_saved`;
  sets `training_time_minutes` to 15;
  sets `adapter_size_mb` to 350.

Tool `run_modern_scenario_test` (owner `validation_agent`):
  via `bash`;
  requires `lora_adapter_saved`;
  adds `style_transfer_evaluated`.

Tool `verify_originality` (owner `validation_agent`):
  via `bash`;
  requires `lora_adapter_saved`;
  adds `originality_passes`.

Tool `run_ai_detector` (owner `validation_agent`):
  via `bash`;
  requires `lora_adapter_saved`;
  adds `detector_score_ok`.

Tool `provide_epub` (owner `user`):
  via `ask_user`;
  adds `epub_file_provided`;
  removes all `epub_file_provided`.

Initially: `example_count` == 0.
Initially: `training_time_minutes` == 0.

  - `orchestrator` spawn `dataset_builder`.
  - `orchestrator` spawn `training_agent`.

    - branch `detector_unavailable`: none.
```
