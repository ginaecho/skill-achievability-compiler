```ce
Skill `nextjs-on-cloudflare`.
Roles: `agent`, `user`.

Tool `install_vinext_skills` (owner `agent`):
  via `bash`;
  requires `shell`;
  adds `vinext_skills_installed`.

Tool `check_skill_availability` (owner `agent`):
  via `bash`;
  adds `vinext_skills_available` or adds `vinext_skills_missing`.

Tool `read_upstream_skill` (owner `agent`):
  via `web_fetch`;
  adds `upstream_skill_read`.

Tool `read_vinext_docs` (owner `agent`):
  via `web_fetch`;
  adds `vinext_docs_read`.

Tool `create_new_project` (owner `agent`):
  via `bash`;
  requires `vinext_new_project_chosen`;
  adds `new_project_scaffolded`.

Tool `run_compatibility_check` (owner `agent`):
  via `bash`;
  requires `existing_nextjs_project`;
  adds `compatibility_checked`.

Tool `migrate_to_vinext` (owner `agent`):
  via `bash`;
  requires `compatibility_checked` and `cloudflare_target_chosen`;
  adds `migrated`.

Tool `develop_and_deploy` (owner `agent`):
  via `bash`;
  requires `vinext_set_up`;
  adds `deployed`.

Tool `choose_project_type` (owner `agent`):
  via `ask_user`;
  picks `project_type` with any of (`project_type` == `new`, `project_type` == `migrate`).

Tool `choose_deployment_target` (owner `agent`):
  via `ask_user`;
  picks `target` with `target` == `cloudflare`.

Initially true: `shell`.

Goal: `deployed`.

Protocol:
  - `agent` uses `check_skill_availability`.
  - `agent` chooses one of (observed):
    - branch `skills_missing`:
      - `agent` uses `install_vinext_skills`.
      - `agent` uses `read_upstream_skill`.
    - branch `skills_available`:
      - `agent` uses `read_upstream_skill`.
  - `agent` uses `read_vinext_docs`.
  - `agent` uses `choose_project_type`.
  - `agent` chooses one of (observed):
    - branch `new_project`:
      - `agent` chooses one of (observed):
        - branch `proceed_new`:
          - `agent` uses `create_new_project`.
        - branch `skip_new`: none.
    - branch `migrate_existing`:
      - `agent` uses `run_compatibility_check`.
      - `agent` chooses one of (observed):
        - branch `proceed_migrate`:
          - `agent` uses `choose_deployment_target`.
          - `agent` uses `migrate_to_vinext`.
        - branch `skip_migrate`: none.
  - agent chooses one of (observed):
    - branch `deploy`:
      - `agent` uses `develop_and_deploy`.
    - branch `skip_deploy`: none.
```
