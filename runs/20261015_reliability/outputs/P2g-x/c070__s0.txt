Skill `comprehensive-research-agent`.
Roles: `agent`, `user`.

Tool `search_and_rank` (owner `agent`):
  via `web_search`;
  requires `research_goal_formulated`;
  adds `sources_ranked`.

Tool `fetch_source` (owner `agent`):
  via `web_fetch`;
  requires `sources_ranked`;
  adds `source_retrieved`;
  picks `fetched` with `fetched` == true or `fetched` == false.

Tool `evaluate_sources` (owner `agent`):
  requires `source_retrieved`;
  adds `source_evaluated`.

Tool `cross_validate_claims` (owner `agent`):
  requires `source_evaluated` and `claims_identified`;
  adds `claims_validated`.

Tool `assemble_report` (owner `agent`):
  via `write`;
  requires `claims_validated` and `all_required_sections_covered`;
  adds `report_written`.

Tool `verify_report` (owner `agent`):
  via `read`;
  requires `report_written`;
  adds `report_verified`;
  sets `gaps_documented` to 1.

Tool `present_findings` (owner `agent`):
  requires `report_verified` and `gaps_documented` == 1;
  adds `research_complete`.

Initially true: `research_goal_formulated`.
Initially: `gaps_documented` == 0.
Goal: `research_complete` and `gaps_documented` == 1.

Protocol:
  - `agent` uses `search_and_rank`.
  - loop `fetch_loop`:
    - `agent` chooses one of (observed):
      - branch `fetch_next`:
        - `agent` uses `fetch_source`.
        - `agent` uses `evaluate_sources`.
      - branch `fetch_done`: none.
    - repeat `fetch_loop`.
  - `agent` uses `cross_validate_claims`.
  - `agent` uses `assemble_report`.
  - `agent` uses `verify_report`.
  - `agent` uses `present_findings`.
