Tool `follow_workers_integration_docs` (owner `agent`): via `web_fetch`; adds `workers_docs_read`.
Tool `deploy_to_cloudflare_workers` (owner `agent`): via `bash`; requires `cloudflare_target_selected`; needs `shell`, `cloudflare_account`; adds `deployed_to_cloudflare_workers`.

    - branch `skills_missing`:

  - `user` chooses one of (observed):

      - `agent` uses `follow_workers_integration_docs`.
    - branch `existing_project`:
      - `agent` uses `migrate_existing_nextjs_project`.
      - `agent` uses `follow_workers_integration_docs`.

      - `agent` uses `follow_workers_integration_docs`.
