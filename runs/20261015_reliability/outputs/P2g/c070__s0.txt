```ce
Skill `comprehensive-research-agent`.
Roles: `agent`.
Tool `search_web` (owner `agent`): via `web_search`; adds `search_results_available`.
Tool `fetch_source` (owner `agent`): via `web_fetch`; requires `source_selected`; adds `source_retrieved`.
Tool `record_failure` (owner `agent`): via `write`; adds `failure_logged`.
Tool `write_tracker` (owner `agent`): via `write`; adds `source_tracker_written`, `found_resources_tracked`.
Tool `write_validation_notes` (owner `agent`): via `write`; requires `source_tracker_written`; adds `validation_phase_written`, `cross_validation_done`, `gaps_documented`.
Tool `write_report` (owner `agent`): via `write`; requires `validation_phase_written`; adds `report_written`, `limitations_section_included`, `specific_coverage_summary_included`.
Tool `verify_report_content` (owner `agent`): via `read`; requires `report_written`; adds `report_verified_by_read`.
Initially true: none.
Goal: all of (`search_results_available`, `source_tracker_written`, `found_resources_tracked`, `validation_phase_written`, `cross_validation_done`, `gaps_documented`, `report_written`, `limitations_section_included`, `specific_coverage_summary_included`, `report_verified_by_read`).
Protocol:
  - `agent` uses `search_web`.
  - `agent` chooses one of (external):
    - branch `results_sufficient`:
      - `agent` uses `write_tracker`.
      - `agent` uses `fetch_source`.
      - `agent` chooses one of (external):
        - branch `fetch_succeeds`: none.
        - branch `fetch_fails`:
          - `agent` uses `record_failure`.
      - `agent` uses `write_validation_notes`.
      - `agent` uses `write_report`.
      - `agent` uses `verify_report_content`.
    - branch `results_insufficient`:
      - `agent` uses `record_failure`.
      - `agent` uses `write_tracker`.
      - `agent` uses `write_validation_notes`.
      - `agent` uses `write_report`.
      - `agent` uses `verify_report_content`.
```
