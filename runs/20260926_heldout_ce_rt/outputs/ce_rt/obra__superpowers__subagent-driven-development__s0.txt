```ce
Skill `subagent-driven-development`.
Roles: `controller`, `implementer`, `reviewer`.
Tool `create_workspace` (owner `controller`): via `bash`; adds `workspace_ready`.
Tool `write_ledger` (owner `controller`): via `write`; requires `workspace_ready`; adds `ledger_created`.
Tool `finish_cleanup` (owner `controller`): via `bash`; requires `ledger_created`; adds `workspace_deleted`.
Initially true: none.
Goal: workspace_ready and ledger_created and workspace_deleted.
Protocol:
  - `controller` uses `create_workspace`.
  - `controller` uses `write_ledger`.
  - loop `tasks`:
    - spawn `implementer`.
    - spawn `reviewer`.
    - `controller` chooses one of (observed):
      - branch `approved`: none.
      - branch `needs_fix`:
        - loop `fix_round`:
          - spawn `implementer`.
          - spawn `reviewer`.
          - repeat `fix_round`.
    - repeat `tasks`.
  - spawn `reviewer`.
  - `controller` uses `finish_cleanup`.
```
