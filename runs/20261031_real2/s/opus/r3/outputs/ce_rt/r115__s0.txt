Skill `task-execution-engine`.

Goal: `all_tasks_processed`.
Protocol:
  - loop `tasks`:
    - `agent` uses `get_next_task`.
    - `agent` chooses one of (observed):
      - branch `implemented`:
        - `agent` uses `implement_task`.
        - `agent` uses `verify_criteria`.
        - `agent` uses `mark_done`.
      - branch `blocked`:
        - `agent` uses `mark_failed`.
    - `agent` chooses one of (external):
      - branch `more_tasks`:
        - repeat `tasks`.
      - branch `no_tasks_remain`:
        - `agent` uses `check_status`.
