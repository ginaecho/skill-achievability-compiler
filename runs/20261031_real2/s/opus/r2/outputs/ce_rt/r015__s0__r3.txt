```ce
Skill `fowler-refactoring`.
Roles: `agent`.
Tool `build_tests` (owner `agent`): via `write`; adds `baseline_tests`.
Tool `run_tests` (owner `agent`): via `bash`; requires `baseline_tests`; adds `tests_green`.
Tool `refactor_step` (owner `agent`): via `edit`; requires `baseline_tests`; adds `refactored`; removes `tests_green`.
Tool `revert` (owner `agent`): via `bash`; requires `baseline_tests`; adds `tests_green`.
Initially true: `code_present`.
Goal: `refactored` and `tests_green`.
Protocol:
  - `agent` uses `build_tests`.
  - `agent` uses `run_tests`.
  - loop `refactor_loop`:
    - `agent` uses `refactor_step`.
    - `agent` uses `run_tests`.
    - `agent` chooses one of (observed):
      - branch `step_green`: none.
      - branch `step_failed`:
        - `agent` uses `revert`.
    - repeat `refactor_loop`.
```
