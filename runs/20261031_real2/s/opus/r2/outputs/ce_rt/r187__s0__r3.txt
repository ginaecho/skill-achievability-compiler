Skill `fathom-debug-bundle`.
Roles: `agent`, `user`.
Tool `collect_diagnostics` (owner `agent`): via `bash`; needs `fathom_api_key`; requires `environment_known`; adds `diagnostics_collected`.
Tool `reproduce_synthetic` (owner `agent`): via `bash`; needs `fathom_test_account`; requires `diagnostics_collected`; adds `reproduced`.
Tool `record_env_differences` (owner `agent`): via `write`; requires `diagnostics_collected`; adds `env_differences_recorded`.
Tool `rotate_credentials` (owner `agent`): via `fathom_console`; needs `fathom_account`; adds `credentials_rotated`.
Tool `write_bundle` (owner `agent`): via `write`; requires `diagnostics_collected` and ( `reproduced` or `env_differences_recorded` ) and `issue_owner_known` and `approved_destination`; adds `bundle_written`, `bundle_has_owner`, `bundle_has_scope`, `bundle_has_evidence`, `bundle_has_escalation`.
Tool `redact_bundle` (owner `agent`): via `edit`; requires `bundle_written` and `redaction_policy`; adds `bundle_redacted`.
Initially true: `issue_owner_known`, `environment_known`, `approved_destination`, `redaction_policy`.
Goal: `bundle_written` and `bundle_redacted` and `bundle_has_owner` and `bundle_has_scope` and `bundle_has_evidence` and `bundle_has_escalation`.
Protocol:
  - `agent` uses `collect_diagnostics`.
  - `agent` chooses one of (external):
    - branch `reproduced`:
      - `agent` uses `reproduce_synthetic`.
    - branch `cannot_reproduce`:
      - `agent` uses `record_env_differences`.
  - `agent` chooses one of (observed):
    - branch `credentials_present`:
      - `agent` uses `rotate_credentials`.
    - branch `no_credentials`: none.
  - `agent` uses `write_bundle`.
  - `agent` uses `redact_bundle`.
