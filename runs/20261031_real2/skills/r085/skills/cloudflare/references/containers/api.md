# Containers API

Use the [Container interface]([url-1]) for the current SDK methods, signatures, properties, and examples. Use the [Durable Object Container API]([url-2]) when working directly with the runtime rather than the SDK class.

| Task | Documentation |
| --- | --- |
| Forward HTTP or WebSocket requests | [Request methods]([url-3]) |
| Start a process, wait for ports, stop, or destroy it | [Start and stop]([url-4]) |
| React to startup, exit, errors, or idle expiry | [Lifecycle hooks]([url-5]) |
| Inspect state or keep background work active | [State and monitoring]([url-6]) |
| Schedule callbacks without replacing the SDK's alarm handler | [Scheduling]([url-7]) |
| Address named instances, select stateless instances, or switch request ports | [Utility functions]([url-8]) |
| Communicate over TCP from a Durable Object | [TCP port API]([url-9]) |
