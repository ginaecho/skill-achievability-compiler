Skill `quarterly-finance-report`.
Roles: `coordinator`, `fetcher`, `expense_analyst`, `revenue_analyst`, `tax_specialist`, `tax_verifier`, `writer`.
Tool `fetch_financials` (owner `fetcher`): via `read`; requires `quarter_selected`; adds `financials_fetched`, `revenue_positive`, `expense_nonnegative`, `line_items_available`.
Tool `analyze_expenses` (owner `expense_analyst`): via `reply`; requires `expense_nonnegative` and `line_items_available`; adds `expense_analyzed`, `expense_analysis_ready`, `expense_analysis_substantive`.
Tool `classify_revenue` (owner `revenue_analyst`): via `reply`; requires `revenue_positive` and `expense_analyzed`; adds `revenue_classified`.
Tool `lookup_tax_rules` (owner `tax_specialist`): via `web_search`; requires `high_branch`; adds `tax_rules_found`.
Tool `audit_high_revenue` (owner `tax_specialist`): via `reply`; requires `high_branch` and `tax_rules_found`; adds `audit_report_ready`, `audit_report_substantive`.

Tool `approve_standard` (owner `tax_verifier`): via `write`; requires `standard_branch`; adds `approval_exists`, `approval_positive`, `approval_recorded`.

Tool `report_result_to_user` (owner `coordinator`): via `reply`; requires `report_delivered` and `delivered_path_known` and `approval_exists` and `approval_positive` and (`high_branch` or `standard_branch`); adds `user_reported`.
