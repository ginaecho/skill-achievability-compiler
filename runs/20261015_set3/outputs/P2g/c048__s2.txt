```ce
Skill `research-summarizer`.
Roles: `agent`, `user`.
Tool `read_source_files` (owner `agent`): via `read`; adds `sources_available`.
Tool `generate_summary_scaffold` (owner `agent`): via `bash`; requires `sources_available`; adds `scaffold_generated`.
Tool `extract_citations` (owner `agent`): via `bash`; requires `sources_available`; adds `citations_extracted`, `extractor_succeeded`.
Tool `deliver_single_source_brief` (owner `agent`): requires `sources_available` and `scaffold_generated`; adds `single_source_brief_delivered`, `key_findings_anchored`, `quality_rated`, `missing_metadata_marked`.
Tool `deliver_comparison_brief` (owner `agent`): requires `sources_available` and `scaffold_generated`; adds `comparison_brief_delivered`, `comparison_matrix_complete`, `synthesis_delivered`, `quality_rated`, `missing_metadata_marked`, `contradictions_highlighted`.
Tool `deliver_citation_bibliography` (owner `agent`): requires `sources_available` and `citations_extracted` and `extractor_succeeded`; adds `bibliography_delivered`, `bibliography_count_matches_extracted`, `citations_classified`, `missing_metadata_marked`.
Tool `ask_for_more_sources` (owner `agent`): via `ask_user`; requires `comparison_requested` and not `enough_sources_for_comparison`; adds `requested_more_sources`.
Initially true: none.
Initially: `source_count` >= 0.
Goal: (`single_source_request` and all of (`single_source_brief_delivered`, `key_findings_anchored`, `quality_rated`, `missing_metadata_marked`)) or (`comparison_requested` and `enough_sources_for_comparison` and all of (`comparison_brief_delivered`, `comparison_matrix_complete`, `synthesis_delivered`, `quality_rated`, `missing_metadata_marked`)) or (`citation_request` and all of (`bibliography_delivered`, `bibliography_count_matches_extracted`, `citations_classified`, `missing_metadata_marked`)).
Protocol:
  - `agent` uses `read_source_files`.
  - `user` chooses one of (observed):
    - branch `single_source`:
      - `agent` uses `generate_summary_scaffold`.
      - `agent` uses `deliver_single_source_brief`.
    - branch `comparison`:
      - `user` chooses one of (observed):
        - branch `enough_sources`:
          - `agent` uses `generate_summary_scaffold`.
          - `agent` uses `deliver_comparison_brief`.
        - branch `need_more_sources`:
          - `agent` uses `ask_for_more_sources`.
    - branch `citations`:
      - `agent` uses `extract_citations`.
      - `agent` uses `deliver_citation_bibliography`.
```
