Initially true: `git_repo_present`, `template_present`, `description_prepared`, `requirements_prepared`.

Protocol:
  - `agent` uses `get_git_shas`.
  - `agent` uses `read_review_template`.
  - `agent` uses `dispatch_reviewer`.
  - spawn `reviewer`.
  - `reviewer` uses `review_code`.
  - `agent` chooses one of (observed):
    - branch `feedback_has_critical_or_important_issues`:
      - `agent` uses `apply_review_fixes`.
    - branch `feedback_has_only_minor_or_no_issues`:
      - `agent` uses `apply_review_fixes`.

  - use `review_code`.
