```ce
Skill `requesting-code-review`.
Roles: `agent`, `reviewer`.
Tool `get_git_shas` (owner `agent`): via `bash`; needs `shell`; adds `base_sha_known`, `head_sha_known`.
Tool `spawn_reviewer` (owner `agent`): via `agent`; needs `sub_agents`; requires `base_sha_known` and `head_sha_known` and `description_prepared` and `requirements_prepared`; adds `review_requested`.
Tool `review_changes` (owner `reviewer`): via `bash`; needs `shell`; requires `review_requested` and `base_sha_known` and `head_sha_known`; adds `review_completed`.
Tool `apply_review_feedback` (owner `agent`): via `bash`; needs `shell`; requires `review_completed`; removes `critical_issues_open`, `important_issues_open`; adds `feedback_addressed`.
Initially true: none.
Goal: `review_completed` and not `critical_issues_open` and not `important_issues_open`.
Protocol:
  - `agent` uses `get_git_shas`.
  - `agent` uses `spawn_reviewer`.
  - spawn `reviewer`.
  - `reviewer` uses `review_changes`.
  - `agent` chooses one of (observed):
    - branch `critical_or_important_found`:
      - `agent` uses `apply_review_feedback`.
    - branch `only_minor_or_no_issues`: none.
Behaviour of `reviewer`:
  - use `review_changes`.
```
