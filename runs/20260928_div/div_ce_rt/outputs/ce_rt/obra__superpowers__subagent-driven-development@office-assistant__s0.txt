```ce
Skill `subagent-driven-development`.
Roles: `controller`, `implementer`, `reviewer`.
Tool `setup_workspace` (owner `controller`): via `bash`; adds `workspace_ready`.
Tool `read_plan` (owner `controller`): via `read`; requires `workspace_ready`; adds `plan_read`.
Tool `generate_task_brief` (owner `controller`): via `bash`; requires `plan_read`; adds `brief_ready`.
Tool `implement_task` (owner `implementer`): via `bash`; requires `brief_ready`; adds `task_implemented`.
Tool `generate_review_package` (owner `controller`): via `bash`; requires `task_implemented`; adds `review_package_ready`.
Tool `review_task` (owner `reviewer`): via `read`; requires `review_package_ready`; adds `task_reviewed`.
Tool `final_code_review` (owner `reviewer`): via `read`; requires `task_reviewed`; adds `branch_reviewed`.
Tool `delete_workspace` (owner `controller`): via `bash`; requires `branch_reviewed`; adds `workspace_deleted`.
Initially true: none.
Goal: `task_implemented` and `task_reviewed` and `branch_reviewed`.
Protocol:
  - `controller` uses `setup_workspace`.
  - `controller` uses `read_plan`.
  - `controller` uses `generate_task_brief`.
  - spawn `implementer`.
  - `implementer` uses `implement_task`.
  - `implementer` tells `controller` `report`.
  - `controller` uses `generate_review_package`.
  - spawn `reviewer`.
  - `reviewer` uses `review_task`.
  - `reviewer` tells `controller` `review_result`.
  - `controller` chooses one of (observed):
    - branch `approved`:
      - `reviewer` uses `final_code_review`.
    - branch `needs_fix`:
      - `implementer` uses `implement_task`.
      - `controller` uses `generate_review_package`.
      - `reviewer` uses `review_task`.
      - `reviewer` uses `final_code_review`.
```
