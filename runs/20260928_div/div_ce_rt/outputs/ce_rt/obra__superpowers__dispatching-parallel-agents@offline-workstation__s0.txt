Skill `dispatching-parallel-agents`.
Roles: `agent`, `sub_a`, `sub_b`.
Tool `fix_domain_a` (owner `sub_a`): via `bash`; adds `domain_a_fixed`.
Tool `fix_domain_b` (owner `sub_b`): via `bash`; adds `domain_b_fixed`.
Tool `run_full_suite` (owner `agent`): via `bash`; requires `domain_a_fixed` and `domain_b_fixed`; adds `tests_pass`.
Initially true: none.
Goal: `domain_a_fixed` and `domain_b_fixed` and `tests_pass`.
Protocol:
  - spawn `sub_a`.
  - spawn `sub_b`.
  - `sub_a` uses `fix_domain_a`.
  - `sub_b` uses `fix_domain_b`.
  - `sub_a` tells `agent` `domain_a_done`.
  - `sub_b` tells `agent` `domain_b_done`.
  - `agent` uses `run_full_suite`.
