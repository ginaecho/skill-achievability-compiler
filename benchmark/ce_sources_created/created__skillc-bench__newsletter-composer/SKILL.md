# Monthly newsletter

Goal: the newsletter is delivered to every subscriber on the `members` audience.

1. Collect the month's highlights from `highlights.md`.
2. Write the newsletter in HTML (header, three stories, events, footer with unsubscribe link).
3. Create a campaign in Mailchimp for the `members` audience with that HTML and send it.
4. Report the campaign id and the number of recipients.
