# Grant proposal drafter

1. Read `program_notes.md` (goals, population, budget lines).
2. Draft `proposal.md` with sections: Statement of Need, Approach, Outcomes and Evaluation, Budget Narrative (max 3 pages).
3. Check the draft against the funder's criteria listed in the notes and add a compliance checklist at the end.
4. Optional: if the organization has a Grants.gov account, the user can submit the final PDF there themselves.
