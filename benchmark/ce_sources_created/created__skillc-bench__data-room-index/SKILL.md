# Data room index

1. Walk the `diligence/` folder and list every file with path, size, type and last-modified date.
2. Number the documents hierarchically by folder (1, 1.1, 1.1.1 ...).
3. Write `index.csv` and `index.md`.
4. Optional: the deal team may later upload the index to Datasite; that step is not part of this skill.
