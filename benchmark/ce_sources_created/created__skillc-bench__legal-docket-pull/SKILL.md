# Docket update

1. Log in to PACER with the firm's account and open the docket report for the case number the user gives.
2. Download the docket entries filed since the last update date.
3. Summarize each new filing in two sentences (filer, relief sought, deadlines created).
4. Save the summary as `docket_update.md` and list any new deadlines at the top.
