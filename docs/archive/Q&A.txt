A: What we made: a compiler that checks an agent skill before execution. It catches declared plans with missing tools, unreachable goals, impossible budgets, or invalid multi-agent handoffs. An achievable verdict includes an abstract witness path, not a guarantee of real-world success. An impossible verdict identifies the blocker relative to the declared capabilities and model assumptions.

How we made it: we split the system at a trust boundary. A deterministic front end, an embedded formal declaration, or optional untrusted LLM compaction produces a pack of tool preconditions, effects, goals, and a protocol. A Python checker combines Z3-backed reachability with MPST-style protocol analysis. Coq mechanizes the underlying refutation-soundness theorem, not the entire Python implementation.
