\paragraph{Fresh compaction and independent actual execution.}
For each task and each exact model, \id{gpt-5.3-codex} and
\id{gpt-5.6-sol}, we run \PilotRepeats{} fresh compaction trials and
\PilotRepeats{} separate execution trials: \PilotExecutions{} paired
observations in total. Each execution receives the original natural-language
skill, request, and available-tool description, but not the formal pack,
prediction, independent verifier, or any previous trial's messages. Each
compactor and executor has a private home, session, working directory, and
temporary directory; discovery of ambient configuration and skills, history
sharing, and memory are disabled. Repeats are fresh sessions, not independent
draws of new skills.

The compiler parses Controlled English, binds the declared requirements to
the actual environment grants, and performs deterministic static validation.
Its bounded syntax retry and guarded repair, when used, are included in
compaction accounting. The executor instead invokes a real Python process
through one sandbox tool in its own disposable container. The verifier
independently inspects the resulting file and checks the requested goal.
It is not an LLM judge, a narrated execution, or a simulated tool response.
Both models use Copilot subscription inference through the installed
1.0.105 client runtime. An official SDK request handler guards the
\emph{complete HTTP request on every turn}, including generated tool
history; WebSocket inference is disabled. Hosted model weights and server
hardware are not under our control.
