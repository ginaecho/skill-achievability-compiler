from skillc.integrations.agent_framework import skillc_monitor

monitor = skillc_monitor(runtime="foundry-hosted", root=state_dir,
                         plan_path=reviewed_plan, strict=True, fail_open=False)
agent = Agent(client=client, tools=tools, middleware=monitor.middleware_for("Writer"))

In Agent 365 the agent's tool loop is Microsoft Agent Framework; skillc sits inside the tool-call path, so a refused tool cannot run. This demo replays published incidents through the same monitor code, offline.

Traces are replayed from benchmark/interaction_cases/. Every skillc decision and latency on the right is computed live by skillc.monitor.Monitor, with the case's prohibited rules stripped. No model is called.
