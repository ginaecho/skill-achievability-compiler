# Finance report certification

Use this procedure for a finance BI report that needs certification.

Tools: `assemble_finance_report`, `record_finance_review`.

## Workflow
1. Run `assemble_finance_report` for the finance report.
2. Run `record_finance_review` to certify the report.

You are finished when the finance report is **certified**.
