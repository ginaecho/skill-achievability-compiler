# Alert handler selection

Use this procedure when a coordinator selects an urgent or routine alert path.

Two participants take part: a **coordinator** and a **handler**.
Tools: `page_oncall`, `file_ticket`.

## Workflow
1. The coordinator chooses the urgent path or the routine path.
2. For the urgent path, the handler uses `page_oncall`.
3. For the routine path, the handler uses `file_ticket`.

You are finished when the incident is **handled**.
