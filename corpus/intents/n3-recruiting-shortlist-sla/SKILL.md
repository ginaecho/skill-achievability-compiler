# Recruiting shortlist SLA

Tools: `search_candidate_pool`, `send_shortlist_to_manager`.

## Workflow
1. Run `search_candidate_pool` for the open role.
2. Run `send_shortlist_to_manager` after the shortlist is ready.
3. Complete with a sent shortlist and turnaround under 3 days.

You are finished when the requested recruiting shortlist sla task is **complete**.
