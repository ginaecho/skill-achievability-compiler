# Article copy review

Use this procedure when an editor may revise copy repeatedly before publication.

Tools: `check_draft`, `revise_copy`, `publish_article`.

## Workflow
1. Start the `copy_cycle`.
2. In each cycle, use `check_draft` to review the draft.
3. Choose the revise path or the publish path.
4. On the revise path, use `revise_copy`, then continue `copy_cycle`.
5. On the publish path, use `publish_article`.

You are finished when the article is **published**.
