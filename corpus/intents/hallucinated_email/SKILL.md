# Flight email confirmation

Use this procedure for a customer flight request that ends with an emailed confirmation.

Tools: search, filter, book, send_email.

## Workflow
1. Use `search` to find flights for the requested itinerary.
2. Use `filter` to select the matching flight options.
3. Use `book` to reserve the chosen flight.
4. Use `send_email` to send the confirmation email to the customer.

You are finished when the flight is **booked** and the confirmation email is **sent**.
