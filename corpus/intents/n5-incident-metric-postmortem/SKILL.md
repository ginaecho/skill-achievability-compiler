# Incident metric postmortem

Use this procedure for an ML operations incident postmortem.

Tools: `collect_incident_metrics`, `deliver_postmortem_brief`.

Two participant roles are involved: a **lead** and a runtime **reviewer**.

## Workflow
1. The lead runs `collect_incident_metrics`.
2. Start a reviewer participant at run time.
3. The lead runs `deliver_postmortem_brief`.

You are finished when the postmortem brief is **delivered**.
