# Record a venue confirmation

Use this procedure when an event_planner follows up on a venue request.

Tools: `request_venue`, `record_reply`.

## Workflow
1. Run `request_venue` for the event space.
2. Run `record_reply` for the venue response.

You are finished when the venue is **confirmed**.
