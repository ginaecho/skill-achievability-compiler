# DSAR response letter

Use this procedure for a privacy officer answering a data subject access request.

Tools: `intake_request`, `locate_records`, `send_response`.

## Workflow
1. Use `intake_request` to log the request.
2. Use `locate_records` to gather responsive records.
3. Use `send_response` to send the response letter.

You are finished when records are **located** and the response is **sent**.
