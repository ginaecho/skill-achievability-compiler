# Customer flight notification

Use this procedure to book a flight and notify the customer so the confirmation reaches them.

Tools: search, filter, book, notify_customer.

## Workflow
1. Use `search` to find flights for the customer itinerary.
2. Use `filter` to choose suitable flight results.
3. Use `book` to reserve the selected flight.
4. Use `notify_customer` so the confirmation reaches the customer.

You are finished when the flight is **booked** and the confirmation is **sent**.
