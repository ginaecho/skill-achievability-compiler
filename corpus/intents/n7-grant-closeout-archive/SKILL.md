# Grant closeout archive

Use this procedure when a research administrator closes out an award file.

Tools: `collect_closeout_forms`, `reconcile_award_ledger`, `submit_closeout_packet`, `archive_award_file`.

## Workflow
1. Use `collect_closeout_forms` to gather the forms.
2. Use `reconcile_award_ledger` for the ledger.
3. Use `submit_closeout_packet` for the closeout packet.
4. Use `archive_award_file` for the award file archive.

You are finished when the closeout packet is **packet_submitted** and the award file is **file_archived**.
