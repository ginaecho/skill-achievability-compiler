# Feature review sprint

Use this procedure for a coordinator running a feature marketing review sprint with a reviewer added during the run.

Tools: `collect_assets`, `review_assets`, `schedule_feature`.

## Workflow
1. The coordinator uses `collect_assets` to gather campaign assets.
2. Add a reviewer participant during the run.
3. The reviewer uses `review_assets` to review the assets.
4. The coordinator uses `schedule_feature` to schedule the feature.

You are finished when the feature is **scheduled**.
