# Research data deposit

Use this procedure when a data librarian deposits a dataset for a research group.

Tools: `screen_dataset`, `mint_dataset_doi`, `publish_repository_record`.

## Workflow
1. Use `screen_dataset` to screen the dataset.
2. Use `mint_dataset_doi` to mint the DOI.
3. Use `publish_repository_record` to publish the repository record.

You are finished when the DOI is **doi_minted** and the repository record is **record_published**.
