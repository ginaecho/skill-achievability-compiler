# Termination notice publishing

Tools: `draft_termination_notice`, `publish_termination_notice`.

## Workflow
1. Run `draft_termination_notice` for the employee case.
2. Run `publish_termination_notice` after the notice is drafted.

You are finished when the requested termination notice publishing task is **complete**.
