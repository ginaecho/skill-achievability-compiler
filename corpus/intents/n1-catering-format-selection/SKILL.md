# Select a catering format

Use this procedure when an event_manager selects a catering format for a caterer.

Tools: `stage_banquet`, `stage_reception`.

Two participants take part: an **event_manager** and a **caterer**.

## Workflow
1. The event_manager chooses the banquet branch or the reception branch.
2. For the banquet branch, the caterer runs `stage_banquet`.
3. For the reception branch, the caterer runs `stage_reception`.

You are finished when catering is **staged**.
