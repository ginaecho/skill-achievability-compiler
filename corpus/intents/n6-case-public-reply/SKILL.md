# Case public reply

Use this procedure when a support case needs a public reply posted for the customer.

Tools: `draft_reply`, `publish_reply`.

## Workflow
1. Use `draft_reply` to prepare the public reply.
2. Use `publish_reply` to publish the reply on the support case.

You are finished when the public reply is **published**.
