# Accommodation letter workflow

Use this procedure when an access coordinator prepares a school accommodation letter.

Tools: `verify_accommodation_request`, `prepare_accommodation_letter`, `send_school_letter`.

## Workflow
1. Use `verify_accommodation_request` to verify the request.
2. Use `prepare_accommodation_letter` to prepare the letter.
3. Use `send_school_letter` to send the letter.

You are finished when the letter is **letter_sent**.
