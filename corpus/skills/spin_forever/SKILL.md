# Publish a report

Your job is finished when the report is **published**.

## Tools

Tools: draft.

- `draft` marks the report **drafted**.

## Workflow

Loop:

1. Draft the report.
2. Review what you have. If it still needs work, go back to the start of
   the loop.

Keep going round until the report is out.
